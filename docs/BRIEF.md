# InPlace Landing — בריף עיצוב ותוכנית ביצוע

נגזר ממסמך המחקר 24.08.2026 + הכרעות בעלים (#194–#209, שיחת 24.08). המסמך הזה הוא חוזה הביצוע; המחקר המלא נשאר מחוץ לריפו הציבורי.

## 1. היררכיית מסרים

1. **הבטחה:** רואים לפני שמשלמים.
2. **הבעיה:** פערי מחיר, קבלה חלקית, זיכוי שנשכח, תשלום בלי שרשרת מלאה.
3. **המנגנון:** ספקים → מחירונים → הזמנות → קבלה → חשבוניות → זיכויים → דרישות → תשלום → בנק. הכול מחובר.
4. **העוזר:** שואלים את העסק, מקבלים תשובה עם ראיות (מקור, עדכניות, הרשאה).
5. **הוכחה:** UI אמיתי, דמו מונחה, שלושה תפקידים, אבטחה, מחשבון שקוף.
6. **פעולה:** נסו דמו חי · פתחו סביבת פיילוט.

## 2. ארכיטקטורת מידע (13 סעיפים)

ניווט → Hero → רצועת הוכחה → 4 דליפות → מסלול הכסף (scroll) → העוזר → שלושה תפקידים → דמו מונחה → ROI → תמחור → אבטחה ואמון → סיפור לקוח (placeholder) → FAQ + CTA → Footer.

## 5. ארכיטקטורת הדמו וגבולות אבטחה

- אתר סטטי; אפס backend, אפס Supabase, אפס credentials. הכול fixtures דטרמיניסטיים ב-TS.
- אין iframe לייצור, אין משתמש משותף, אין upload, אין מפתח מודל.
- דמו = רכיבי product-ui משוכפלים בשליטה + נתוני תרחיש קבועים המשקפים סמנטיקה אמיתית (three-way match, סבילויות ₪0.05/₪1/1%/2%).
- הדמו של העוזר משקף את חוזה ASSISTANT.md: ערך+יחידה+חלון+as_of, מקור שניתן "לפתוח" (מסך דמו), מצבים complete/partial/not_measured/not_permitted. אין מודל חי.

## 6. מצבי העוזר בדף

שאלות מודגמות (מיפוי לכלים אמיתיים): "למה החשבונית חסומה?" (explain_invoice_block, קודי סיבה) · "כמה כסף ממתין לזיכוי?" (get_open_credits) · "אילו הזמנות נשלחו ולא אושרו?" (get_orders_awaiting_confirmation) · "אילו תנועות בנק לא מותאמות?" (accountant בלבד — מדגים not_permitted לרכש).

## 7. Asset manifest (Higgsfield — לאחר אישור בעלים)

1. Hero loop 16:9, ‏6–8 שניות, seamless, ללא טקסט/לוגו/אנשים/UI — פרומפט הבסיס מהמחקר.
2. Poster תואם (LCP + reduced motion).
3. גרסת מובייל קלה (crop אנכי).
- manifest יתועד: prompt, model, duration, aspect, seed, סטטוס אישור. עד אז: רקע CSS שקט (לא חוסם השקה).

## 9. תקציב ביצועים

LCP ≤ 2.5s ‏· INP ≤ 200ms ‏· CLS ≤ 0.1 ‏· JS ראשוני ≤ 170KB gzip ‏· פונטים מקומיים woff2 ‏· media lazy ‏· אין canvas ב-LCP.
